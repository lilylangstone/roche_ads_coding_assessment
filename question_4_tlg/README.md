# Question 4: Tables, Listings and Graphics

## Overview

This solution produces the required adverse event table, visualisations and
listing using the `pharmaverseadam::adae` dataset.

The outputs are generated by three R programs and saved to the `output`
directory.

## Programs

### `01_create_ae_summary_table.R`

Creates an adverse event summary table for treatment-emergent adverse events
(`TRTEMFL == "Y"`).

The table:

- Summarises adverse events by treatment using `ACTARM`.
- Includes System Organ Class (`AESOC`) and adverse event term (`AETERM`).
- Displays the number and percentage of subjects experiencing each event.
- Includes the total number of subjects.
- Orders adverse events by descending frequency.

Output:

`output/ae_summary_table.html`

### `02_create_visualizations.R`

Creates two adverse event visualisations.

**AE Severity by Treatment**

Displays the distribution of adverse event severity across actual treatment
groups.

Output:

`output/ae_severity_by_treatment.png`

**Top 10 Adverse Events**

Displays the 10 most frequent adverse events by subject incidence, with
95% confidence intervals.

Output:

`output/top_10_ae_incidence.png`

### `03_create_listings.R`

Creates a subject-level listing of treatment-emergent adverse events.

The listing includes:

- Subject identifier
- Treatment
- Adverse event term
- Severity
- Relationship to treatment
- Start date
- End date

Records are ordered by subject and adverse event start date.

Output:

`output/ae_listings.html`

## Running the Programs

From the repository root, the programs can be run in order:

```r
source("question_4_tlg/01_create_ae_summary_table.R")
source("question_4_tlg/02_create_visualizations.R")
source("question_4_tlg/03_create_listings.R")
```

The generated files will be written to the `output` directory.
